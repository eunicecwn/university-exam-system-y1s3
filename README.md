University Examination System

Java | Object-Oriented Programming 

📌 Project Overview

This project is a University Examination System developed using Java and the principles of Object-Oriented Programming (OOP).
It simulates the core workflows involved in managing examinations, including student records, subjects, exam registration, result processing, and basic administrative functions.

The system was developed as part of a group project to strengthen understanding of OOP concepts such as encapsulation, inheritance, polymorphism, and abstraction.

🎯 Objectives

Provide a structured system to manage exam-related information.

Apply OOP principles in a real-world academic scenario.

Improve understanding of class design, relationships, and modular programming.

🛠️ Technologies Used

Java (core language)

OOP principles

CLI-based interface (no GUI)

📂 Main Features

Student Management

Add, view, and manage student details

Subject & Exam Management

Register students for exams

Manage subjects and exam entries

Result Processing

Calculate grades

Display and track academic performance

Administrative Functions

Basic validation

Data organization using classes and objects

🧱 OOP Concepts Applied

Encapsulation – Secure handling of student and exam data

Inheritance – Shared attributes between related classes

Polymorphism – Method overriding for specialized behaviours

Abstraction – Cleaner logic separation using abstract classes/interfaces (if applicable)
